# A2-M01 — Passé composé (*passato prossimo*)

## Informations générales

- **Niveau :** A2 (communication quotidienne)
- **Unité :** 1
- **Durée estimée :** 4 h
- **Prérequis :** niveau A1 validé ([[A1-M10-situations-communication-a1]])
- **Type :** cours, exercices corrigés, activité orale
- **Compétences :** raconter des actions passées et terminées
- **Score de validation :** 70 %

## Objectifs pédagogiques

À la fin du module, l'apprenant pourra :

- former le *passato prossimo* avec **avere** ou **essere** ;
- choisir le bon auxiliaire ;
- former les participes passés réguliers et les **15 irréguliers** les plus fréquents ;
- **accorder** le participe avec *essere* ;
- utiliser les marqueurs de temps (*ieri, fa, scorso, già, non… ancora*) ;
- raconter sa journée ou son week-end.

## Situation de départ

**Contexte :** lundi matin, Chiara demande à Grâce : *« Allora, com'è andato il weekend a Firenze? »* Grâce veut raconter : elle est partie samedi, elle a visité le Duomo, elle a mangé une pizza, elle est rentrée tard.

**Question de départ :** 👉 *En français on dit « j'ai visité » mais « je suis partie ». Est-ce pareil en italien ?* (Réponse : **presque toujours oui** ! Bonne nouvelle pour les francophones.)

## Vocabulaire essentiel — marqueurs du passé

| Italien | Français |
|---|---|
| ieri | hier |
| l'altro ieri | avant-hier |
| ieri sera / ieri mattina | hier soir / hier matin |
| stamattina | ce matin |
| la settimana scorsa | la semaine dernière |
| il mese scorso / l'anno scorso | le mois dernier / l'année dernière |
| sabato scorso | samedi dernier |
| due giorni **fa** | il y a deux jours |
| un anno **fa** | il y a un an |
| già | déjà |
| non … ancora | ne … pas encore |
| appena | à l'instant, tout juste |
| mai | jamais (*Sei mai stato a Roma?* = Es-tu déjà allé à Rome ?) |
| finalmente | enfin |

> [!warning] *fa* se place **après**
> « il y a deux jours » → *due giorni **fa*** (et non *fa due giorni*).

---

## Point de grammaire 1 — La formation

### Règle

**auxiliaire *avere* ou *essere* au présent + participe passé**

| | avec **avere** : *mangiare* | avec **essere** : *partire* |
|---|---|---|
| io | **ho** mangiato | **sono** partito/a |
| tu | **hai** mangiato | **sei** partito/a |
| lui / lei / Lei | **ha** mangiato | **è** partito/a |
| noi | **abbiamo** mangiato | **siamo** partiti/e |
| voi | **avete** mangiato | **siete** partiti/e |
| loro | **hanno** mangiato | **sono** partiti/e |

### Les participes passés réguliers

| Infinitif | Participe | Exemple |
|---|---|---|
| -**are** | -**ato** | parlare → parl**ato** |
| -**ere** | -**uto** | credere → cred**uto** · avere → av**uto** |
| -**ire** | -**ito** | dormire → dorm**ito** · capire → cap**ito** |

**Exemple résolu — « Nous avons dormi à l'hôtel » :**
1. *dormire* → groupe -ire → participe **dormito**
2. Verbe « normal » avec objet/sans mouvement → auxiliaire **avere**
3. *noi* → **abbiamo**
4. → **Abbiamo dormito in albergo.**

---

## Point de grammaire 2 — Les participes irréguliers

Surtout des verbes en **-ere**. Apprenez-les par groupes de sons :

| Infinitif | Participe | | Infinitif | Participe |
|---|---|---|---|---|
| fare | **fatto** | | prendere | **preso** |
| dire | **detto** | | chiudere | **chiuso** |
| leggere | **letto** | | decidere | **deciso** |
| scrivere | **scritto** | | spendere | **speso** |
| rompere | **rotto** | | perdere | **perso** |
| vedere | **visto** | | mettere | **messo** |
| rispondere | **risposto** | | aprire | **aperto** |
| chiedere | **chiesto** | | offrire | **offerto** |
| rimanere | **rimasto** | | vivere | **vissuto** |
| essere | **stato** | | venire | **venuto** |
| nascere | **nato** | | morire | **morto** |
| scegliere | **scelto** | | bere | **bevuto** |

> [!tip] Astuce mémoire
> Beaucoup ressemblent au français : *fatto* (fait), *detto* (dit), *scritto* (écrit), *messo* (mis), *preso* (pris), *aperto* (ouvert), *offerto* (offert), *morto* (mort), *nato* (né).

---

## Point de grammaire 3 — *Avere* ou *essere* ?

### Règle

| **avere** | **essere** |
|---|---|
| La plupart des verbes, surtout ceux qui ont un **complément d'objet** : *mangiare, comprare, visitare, fare, leggere, studiare…* | Les verbes de **mouvement** d'un lieu à l'autre : *andare, venire, arrivare, partire, tornare, entrare, uscire, salire, scendere* |
| Beaucoup de verbes **sans** objet aussi : *dormire, lavorare, parlare, camminare, viaggiare, piangere* | Les verbes d'**état** ou de **changement d'état** : *essere, stare, restare, rimanere, diventare, nascere, morire* |
| | Les verbes **pronominaux** (réfléchis) : *svegliarsi → mi sono svegliato* |

> [!info] Différences avec le français
> - *essere* → **sono stato** (j'**ai** été !) : en italien *essere* se conjugue avec lui-même.
> - *piacere* (plaire) → *mi **è** piaciuto* (ça m'a plu).
> - *costare* (coûter) → *è costato* (ça a coûté).
> - *camminare, viaggiare* (marcher, voyager) → **avere**, même si c'est un mouvement : il n'y a pas de point d'arrivée précis.

**Exemple résolu — « Grâce est restée à la maison » :**
1. *restare* = état → **essere**
2. *lei* → **è**
3. participe *restato* + accord au féminin → **restata**
4. → **Grâce è restata a casa.**

---

## Point de grammaire 4 — L'accord du participe

### Avec *essere* → accord avec le **sujet** (comme en français)

| | masc. | fém. |
|---|---|---|
| singulier | Marco è andat**o** | Grâce è andat**a** |
| pluriel | Marco e Luca sono andat**i** | Grâce e Chiara sono andat**e** |
| mixte | Grâce e Marco sono andat**i** | |

### Avec *avere* → **pas d'accord** en général

*Grâce **ha** mangiato una pizza.* (pas *mangiata*)
*Le ragazze **hanno** studiato.* (pas *studiate*)

> L'exception avec les pronoms (*l'ho vista*) sera vue en [[A2-M04-pronoms-directs-indirects]].

---

## Point de grammaire 5 — Place des adverbes

*già, ancora, mai, appena, sempre* se placent **entre l'auxiliaire et le participe** :

- *Ho **già** mangiato.* — J'ai déjà mangé.
- ***Non** ho **ancora** finito.* — Je n'ai pas encore fini.
- *Sei **mai** stato in Italia?* — Tu es déjà allé en Italie ?
- *Siamo **appena** arrivati.* — Nous venons d'arriver.

> [!tip] « Venir de » + infinitif
> Le français « je viens d'arriver » se traduit par **appena** + passé composé : *Sono appena arrivata.*

## Dialogue contextualisé

```text
Chiara : Ciao Grâce! Allora, com'è andato il weekend a Firenze?
Grâce  : Benissimo! Sono partita sabato mattina con Marco.
Chiara : In treno?
Grâce  : Sì, abbiamo preso il regionale delle otto. Siamo arrivati alle nove.
Chiara : E che cosa avete fatto?
Grâce  : Prima abbiamo visitato il Duomo, poi abbiamo camminato fino al
         Ponte Vecchio. Ho fatto un sacco di foto!
Chiara : Avete mangiato bene?
Grâce  : Sì, a pranzo abbiamo mangiato una bistecca, e la sera una pizza.
         Mi è piaciuta molto la città.
Chiara : Siete tornati tardi?
Grâce  : Sì, siamo tornati a mezzanotte. Stamattina mi sono svegliata tardi
         e non ho ancora finito i compiti!
Chiara : Dai, ti aiuto io!
```

## Traduction du dialogue

```text
Chiara : Salut Grâce ! Alors, comment s'est passé le week-end à Florence ?
Grâce  : Très bien ! Je suis partie samedi matin avec Marco.
Chiara : En train ?
Grâce  : Oui, on a pris le régional de huit heures. On est arrivés à neuf heures.
Chiara : Et qu'est-ce que vous avez fait ?
Grâce  : D'abord on a visité le Duomo, puis on a marché jusqu'au
         Ponte Vecchio. J'ai pris plein de photos !
Chiara : Vous avez bien mangé ?
Grâce  : Oui, à midi on a mangé une bistecca, et le soir une pizza.
         La ville m'a beaucoup plu.
Chiara : Vous êtes rentrés tard ?
Grâce  : Oui, on est rentrés à minuit. Ce matin je me suis réveillée tard
         et je n'ai pas encore fini les devoirs !
Chiara : Allez, je t'aide !
```

> [!info] *fare una foto*
> En italien on « **fait** » une photo (*fare una foto*), on ne la « prend » pas.

## Compréhension

1. Avec qui Grâce est-elle partie ? Quand ?
2. Comment sont-ils allés à Florence ?
3. Qu'ont-ils visité ?
4. Pourquoi dit-on *siamo arrivati* et pas *siamo arrivate* ?
5. Pourquoi *abbiamo camminato* avec *avere* alors que c'est un mouvement ?

## Corrigé

### Compréhension

1. Avec Marco, samedi matin. · 2. En train (le régional de 8 h). · 3. Le Duomo et le Ponte Vecchio. · 4. Grâce + Marco = groupe mixte → masculin pluriel. · 5. *camminare* se construit toujours avec *avere* (pas de point d'arrivée).

### Exercice 1

1-c · 2-a · 3-b · 4-e · 5-d · 6-f

### Exercice 2

1-b · 2-a · 3-b · 4-a · 5-b · 6-b

### Exercice 3

> Sabato scorso io **mi sono svegliata** alle sette. **Ho fatto** colazione e **sono uscita** di casa. Con le mie amiche **sono andata** al mercato. Noi **abbiamo comprato** frutta e verdura. Poi Chiara **è tornata** a casa e io **sono rimasta** in centro. La sera **ho letto** un libro.

**Méthode :** pour chaque verbe, 1) mouvement/état/réfléchi ? → *essere* + accord féminin ; sinon *avere* sans accord. 2) participe régulier ou irrégulier (*fatto, rimasto, letto*).

### Exercice 4

1. Ho già visto il film. · 2. Non sono ancora arrivati. · 3. Sei mai stata a Venezia? · 4. Abbiamo appena finito.

### Exercice 5

1. Ieri ho studiato l'italiano. · 2. Ieri Marco è andato in biblioteca. · 3. Ieri le ragazze sono partite. · 4. Ieri abbiamo scritto una lettera. · 5. Ieri Grâce è stata stanca. *(Pour décrire un état, on dira souvent* era stanca *: voir [[A2-M02-imparfait-description-passe]].)*

### Exercice 6

1. L'anno scorso ho preso il diploma. *(ou : ho preso la maturità)*
2. Tre mesi fa ho cominciato un corso d'italiano.
3. Sono andato/a all'ambasciata la settimana scorsa.
4. Non ho ancora ricevuto la risposta.
5. Ho appena finito il mio dossier. *(dossier = la pratica / la domanda)*

## Critères de réussite

- **Score minimum :** 7/10
- **Activité orale** enregistrée
- **À revoir si erreurs :** 1–3 → Point 2 ; 4–7, 10 → Points 3–4 ; 8–9 → Point 5

## Résumé

- *passato prossimo* = **avere / essere** + participe.
- Participes : **-ato, -uto, -ito** + irréguliers (*fatto, detto, preso, visto, scritto, letto, messo, stato…*).
- **essere** : mouvement vers un lieu, état, changement d'état, verbes réfléchis ; *essere → sono stato*.
- Avec **essere** : accord avec le sujet. Avec **avere** : pas d'accord.
- *già, ancora, mai, appena* entre l'auxiliaire et le participe. *due giorni fa*.
